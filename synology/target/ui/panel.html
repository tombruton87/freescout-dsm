HTTPS with DSM's reverse proxy

        
Third-party packages can't use DSM's certificates directly, but DSM's reverse proxy can front FreeScout with them:

        
    
          
  1. Control Panel → Login Portal → Advanced → Reverse Proxy → Create: source HTTPS, hostname your domain (for instance help.example.com), port 443; destination HTTP, localhost, port 8060.
    2. 
          
  2. Under Custom Header, Create → WebSocket (adds the Upgrade headers), and make sure X-Forwarded-For / X-Forwarded-Proto are passed.
    3. 
          
  3. Control Panel → Security → Certificate → Settings: give that reverse-proxy entry your certificate.
    4. 
          
  4. Here: set the address to https://your.domain, tick Behind DSM's reverse proxy, save.
    5.

Remove FreeScout and everything

        
Removes it all: FreeScout's containers and images, its database, attachments, modules and logs (the Docker volumes), the freescout shared folder with its backups and settings, and then the package itself — DSM's own uninstaller and shared-folder tools finish the job, so nothing is left to do by hand. There is no undo.
